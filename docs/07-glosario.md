# 07 · Glosario

| Término | Definición |
| ------- | ---------- |
| **APT** | Amenaza persistente avanzada: ataque dirigido, sigiloso y prolongado |
| **ASIC / SPU** | Procesador dedicado de Fortinet para acelerar red y seguridad |
| **Antivirus (AV)** | Detección de malware por firmas, heurística y reputación |
| **Application Control** | Identificación y control de aplicaciones en capa 7 |
| **CLI** | Interfaz de línea de comandos |
| **DLP** | Prevención de fuga de datos |
| **DMZ** | Zona intermedia para servicios expuestos a Internet |
| **DNS Filtering** | Bloqueo de dominios maliciosos al resolverlos |
| **EDR** | Detección y respuesta en endpoints |
| **FortiAnalyzer** | Logs, correlación y reportes |
| **FortiGate** | NGFW de Fortinet |
| **FortiGuard** | Servicios de inteligencia y actualizaciones de Fortinet |
| **FortiManager** | Gestión centralizada de dispositivos Fortinet |
| **FortiOS** | Sistema operativo de FortiGate |
| **FortiSandbox** | Análisis de malware en entorno aislado |
| **Flow-based** | Inspección de paquetes al vuelo (rápida) |
| **HA** | Alta disponibilidad (clúster) |
| **IDS** | Sistema de detección de intrusiones (solo alerta) |
| **IPS** | Sistema de prevención de intrusiones (bloquea) |
| **IPsec** | Conjunto de protocolos para VPN cifradas |
| **MFA** | Autenticación multifactor |
| **NAT** | Traducción de direcciones de red |
| **NGFW** | Firewall de nueva generación |
| **Proxy-based** | Inspección con almacenamiento y análisis completo del contenido |
| **Ransomware** | Malware que cifra datos y exige rescate |
| **SASE** | Red y seguridad entregadas desde la nube |
| **Sandbox** | Entorno aislado para ejecutar archivos sospechosos |
| **SD-WAN** | WAN definida por software con selección de ruta por aplicación |
| **Security Fabric** | Plataforma integrada y automatizada de Fortinet |
| **SSL/TLS Inspection** | Descifrado e inspección de tráfico cifrado |
| **Stateful inspection** | Seguimiento del estado de conexiones |
| **UTM** | Gestión unificada de amenazas (todo-en-uno) |
| **VIP** | Virtual IP, usada para publicar servicios (DNAT) |
| **VLAN** | Segmentación lógica de red en capa 2 |
| **WAF** | Firewall de aplicaciones web |
| **Zero-day** | Vulnerabilidad aún sin parche conocido |
| **Zero Trust** | Modelo de "nunca confiar, siempre verificar" |
