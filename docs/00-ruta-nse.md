# 00 · Ruta NSE y cambios 2026

## ¿Qué es el programa NSE?

**NSE (Network Security Expert)** es el programa de capacitación y certificación de Fortinet. Se ofrece a través del **Fortinet Training Institute**. Los niveles iniciales son gratuitos y en línea.

## Requisitos por nivel (programa vigente desde el 15 de julio de 2026)

| Nivel | Requisito |
| ----- | --------- |
| NSE 1 | Completar el curso en línea **Cybersecurity and Cloud Fundamentals** |
| NSE 2 | Completar el curso en línea **Introduction to the Next Generation Firewall** |
| NSE 3 | Curso **FortiGate Operator** + examen en línea |
| NSE 4 | Examen supervisado **FortiOS Administrator** |
| NSE 5 – 7 | Especializaciones (Secure Networking, Security Operations, SASE, Cloud Security) |
| NSE 8 | Examen práctico (nivel experto) |

> Fuente: Fortinet Training Institute Help Desk — *"What are the new certification requirements?"*

## ¿Qué cambió?

A partir de julio de 2026 el programa se reorganizó (ampliado de 5 a 8 niveles). Para los niveles iniciales:

| Antes | Ahora |
| ----- | ----- |
| NSE 1 – Getting Started in Cybersecurity | NSE 1 – Cybersecurity and Cloud Fundamentals |
| NSE 2 – Technical Introduction to Cybersecurity | NSE 2 – Introduction to the Next Generation Firewall |

Históricamente (versiones anteriores) NSE 2 se llamó también **"The Evolution of Cybersecurity"**. Por eso este repo incluye un documento de evolución (`01`) además del temario de NGFW: así sirve para **cualquiera de las versiones**.

## Datos útiles del NSE 2

- Valida que puedes **identificar y describir las funciones centrales de un Next Generation Firewall**.
- Se aprueba con el **examen en línea al final del curso**.
- La certificación está **vigente 2 años** desde que completas el curso.
- Recibes una **insignia digital** (badge) de examen y otra de certificación.
- Renovación: repetir el curso/examen, o completar/renovar cualquier certificación NSE 2 a 7.

> ⚠️ Los requisitos pueden cambiar. Verifica siempre en la [página oficial de NSE 2](https://training.fortinet.com/local/staticpage/view.php?page=nse_2).
